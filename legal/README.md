# legal/ — rights, licence and UK compliance pages

- `build_legal.py` writes `public/{licence,privacy,cookies,terms,disclaimer,accessibility,enquire}/index.html`. Edit the generator, then run `python3 legal/build_legal.py` from the repo root.
- `/rights/` and `/license/` redirect to `/licence/` (`public/_redirects`).
- The shared legal footer on every Great House Farm site is injected by `public/ghf-lang/basecamp.js` (generated by `campus/build_basecamp.py`, function `legalFoot`). Pages that already carry `data-ghf-legal-foot` are skipped.
- `worker/` is the source of the Cloudflare Worker `ghf-enquire` (route `bucklerfamily.estate/enquire/api/*`): it stores enquiries in the D1 database `ghf-enquiries` and forwards each one by Email Routing to the family's verified mailbox (the address is a Worker binding, not in this repo). A push here does not deploy the Worker; it is uploaded through the Workers API.

Template prepared by Sion's Tab agent; not legal advice; review by a qualified solicitor/attorney recommended.
