# Great House Farm Web App

This branch serves the Great House Farm web application at the root of its own Cloudflare Pages project.

- Branch: `ghf-app`
- Cloudflare Pages project: `ghf-app`
- Custom domain: `ghf-app.bucklerfamily.estate`
- Built from the Vite application in `src/` with `npm run build`

The main `main` branch continues to serve the Tŷ Mawr Campus homepage and its `/webapp/` entry.
